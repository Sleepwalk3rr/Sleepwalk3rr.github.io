# 📚 Трекер чтения книг (Book Tracker)

Адаптивное веб-приложение для мониторинга личной читательской активности, анализа прогресса и геймификации процесса чтения.

## 🌟 Основные возможности

- **Управление библиотекой (CRUD):** Добавление новых книг, редактирование информации об авторе и объеме страниц, удаление записей.
- **Отслеживание прогресса:** Визуальный индикатор (progress bar) для каждой книги, расчет процента прочитанного в реальном времени.
- **Статистика и аналитика:** 
  - Автоматический подсчет прочитанных страниц за день, неделю и месяц.
  - Счетчик завершенных книг.
- **Система целей и наград:**
  - Установка ежедневной нормы страниц.
  - Автоматическое уведомление о достижении цели.
  - Разблокировка наград (нашивок) за успехи.
- **Фильтрация:** Быстрая сортировка книг по статусам: *«Читаю»*, *«Закончил»*, *«Отложил»*.
- **Полная адаптивность:** Интерфейс оптимизирован для смартфонов, планшетов и настольных ПК.

## 🛠 Технологии

Проект реализован на «чистых» технологиях (Vanilla Stack) без использования сторонних библиотек и фреймворков, что обеспечивает максимальную производительность:

- **HTML5:** Семантическая структура.
- **CSS3:** Flexbox, Grid, CSS Variables, Media Queries.
- **JavaScript (ES6+):** Манипуляция DOM, расчет статистики, событийная модель.
- **LocalStorage API:** Хранение всех данных пользователя локально в браузере.

Для запуска приложения не требуется установка серверов или дополнительных модулей.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
2. Откройте файл index.html в любом современном браузере.

📁 Структура файлов

index.html — главная страница и структура приложения.
style.css — стили, анимации и адаптивная верстка.
script.js — бизнес-логика, работа с данными и локальным хранилищем.
site resources/ — медиа-файлы (видео-фон, иконки).

🔒 Приватность

Все данные о ваших книгах и прогрессе сохраняются исключительно в LocalStorage вашего браузера. Приложение не передает информацию на сторонние серверы, что гарантирует полную конфиденциальность.
